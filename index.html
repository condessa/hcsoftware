Instalar leva um minuto

Sem registo, sem chave de licença, sem limite de tempo.

  1. 1

    Escolhe o programa

    Cada cartão diz para que serve e em que sistemas corre. Em caso de dúvida, começa pelo HC-Gestão Stocks.

  2. 2

    Descarrega o instalador

    Windows: .exe. Linux: .deb. Se ainda não houver instalador, o botão «Código» leva-te ao repositório.

  3. 3

    Instala e usa

    Duplo clique no .exe, ou no Linux: sudo dpkg -i ficheiro.deb. Os dados ficam no teu computador.

O Windows avisa que não é assinado

É normal em projetos independentes. Clica em «Mais informações» → «Executar mesmo assim».

Faltam dependências no Linux

Se o dpkg reclamar, corre sudo apt-get install -f e volta a tentar.

Queres confirmar o download

O HC-Gestão Stocks publica o sha256 de cada ficheiro na página de releases.
