Guia rápido

Instalar no Windows

O Alumínio Manager não tem instalador: é um ficheiro único. Em quatro passos fica a funcionar — e não precisa de Internet depois de descarregado.

1

Descarregar o programa

Descarrega o ficheiro AluminioManager-1.5.8.exe (95 MB) e guarda-o, por exemplo, na pasta «Transferências».

2

Executar e passar o aviso do Windows

Faz duplo clique no ficheiro. É normal aparecer uma janela azul com este texto:

O Windows protegeu o seu PC
O Microsoft Defender SmartScreen impediu o arranque de uma aplicação desconhecida.

Clica em Mais informações e depois em Executar mesmo assim.

Este aviso aparece a qualquer programa novo que não tenha um certificado de assinatura pago. O Alumínio Manager é gratuito e de código aberto, mas não tem esse certificado anual — por isso o Windows ainda não o conhece.

3

Ligar a base de dados

Os dados ficam no MySQL/MariaDB do computador. Se já tens o XAMPP (ou o MySQL/MariaDB) instalado:

  1. No painel do XAMPP, carrega em Start no MySQL.
  2. Na janela do programa, carrega em «Configurar automaticamente».

Se o programa não encontrar o MySQL, carrega em «Escolher o mysql.exe…» e indica o ficheiro — normalmente C:\xampp\mysql\bin\mysql.exe. O caminho fica guardado para as próximas vezes.

4

Criar a empresa e o administrador

Na primeira utilização o programa pede o nome da empresa e a conta de administrador que quiseres criar. Depois entra diretamente — não existem contas pré-definidas.

Não abriu ou fechou?

O programa escreve um registo em %USERPROFILE%\.config\aluminio-manager\erro.log. Abre esse ficheiro e envia-o para apoio — assim vemos exatamente o que falhou, sem adivinhar.
